Inventaires
- lorsqu'on accède à la master list des ingrédients, rend invisible las partie emplacements, qui n'a rien à voir
- pour les ingrédients, il y a du beurre, du beurre fondu, du beurre salé, etc. Il faudrait gérer le nom générique de l'ingrédient, et ajouter une description avec qualificatif. Ainsi beurre salé ou beurre doux est l'ingrédient générique, et il peut être fondu ou pommade dans la recette --> ajouter le champ descritif dans la recette à côté de l'ingrédient. par ailleurs un ingrédient dans une recette peut être facultatif
- la gestion des ingrédients :
    -  la liste des genres d'ingrédients doit être en menu déroulant. il doit y avoir une option pour gérer la master list des genres d'ingrédients
    - on doit pouvoir changer le nom d'un ingrédient. par exemple : beurre demi-sel --> beurre salé. Pour cela, il faut pouvoir cliquer sur le nom, et ouvrir une fenetre avec la possibilité d'édition, et la liste des recettes associées
    - il faut gérer les fractions dans les quantités. pour les recettes, conserver les quantités soit en décimal, soit en fraction (en fonction de l'entrée)
    - dans l'écran Semaine, le menu qui apparait lorsqu'on modifie un événement est illisibible --> ne rentre pas dans l'écran
    A NOTER DANS LE GUIDE DE PROGRAMMATION : Toujours vérifier que les boutons ou menus rentrent bien dans la largeur des différents écrans. Si ce n'est pas le cas, choisir une auttre approche d'UX.
    - il faudrait pouvoir indiquer le sourcing des ingrédients : marché / internet / boutique, avec un champ de commentaire (URL ou nom du marché...). Cela peut être prérempli par défaut pour une classe d'ingrédient puis modifié / précisé ingrédient par ingrédient
    - dans la recherche des stocks, il faut pouvoir préciser le type d'ingrédient recherché
    - il doit être possible de faire un import / export des données
    - il faut pouvoir gérer la liste des sources de recettes
